# ParekGIT #
Git GUI Client that's focused on simplicity

- Still in development, open to suggestions
- To support the project, please test out the application and report any bugs and/or missing features in [Issues](https://github.com/cherttov/ParekGIT/issues) tab

## Requirements ##
**Operating System**
- Windows 10/11 (x64)
- Linux **(UNTESTED)**
- MacOS **(UNTESTED/NOT COMPILED)**

**Web Rendering Engine ([source](https://docs.tryphotino.io/Photino-Comparison-with-Electron))**
- Windows: [WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/)
- Linux: [WebKitGTK2](https://webkitgtk.org)
- MacOS: [WKWebView](https://developer.apple.com/documentation/webkit/wkwebview)
> **NOTE:** Unlike **Windows** and **MacOS**, **Linux** might not come with a pre-installed WebKitGTK2
